# Security and responsible use

SentinelOps Inspector is a development-preview desktop tool for authorized Microsoft Sentinel and Log Analytics administration.

- Do not publish access tokens, refresh tokens, customer data, or other sensitive log content in GitHub Issues.
- Use the least-privileged permitted workspace access, and follow your organization's application consent and Conditional Access policies.
- Before using this beta in a production organization, review the binary and your organization's software deployment policy.
- To report security-sensitive issues, first use GitHub's private vulnerability reporting if it is enabled for this repository. Otherwise contact the repository owner privately; do not post exploit details or secrets in a public issue.
